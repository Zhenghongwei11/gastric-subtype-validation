# Data manifest

`manifest.tsv` lists the public cohorts referenced by this reproducibility package, together with their primary role (derivation, external validation, or supplementary context).

This repository does not redistribute raw expression matrices. Please download the expression data and clinical supplements directly from the GEO or GDC links in `manifest.tsv`, then run the scripts under `scripts/analysis/` to regenerate the derived tables in `results/` and the figures in `plots/publication/`.
